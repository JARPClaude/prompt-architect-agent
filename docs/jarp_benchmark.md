# JARP Quality Benchmark — Prompt Architect v1.0.0

The benchmark is set by **Dark Strategist v2.5.1** — the most architecturally complete prompt in the JARP ecosystem.

## The 8 Benchmark Criteria

Any JARP-native prompt missing any criterion has at minimum one SERIOUS finding.

| # | Criterion | Standard |
|---|---|---|
| 1 | Explicit identity with clear prohibitions | Defines IS and IS NOT. No ambiguity. |
| 2 | Executable mission with scope limits | Action verbs. Out-of-scope defined. |
| 3 | Deterministic behavioral rules | Specific and testable. No escape clauses. |
| 4 | Standardized output format with templates | All blocks templated. Edge cases handled. |
| 5 | Session state management | States defined with anchoring tokens. |
| 6 | Version governance with CHANGELOG | Version in header. Full change history. |
| 7 | Pre-release self-audit requirement | REPORT_ID logged in CHANGELOG. |
| 8 | Cross-reference integrity | Every internal reference verified. |
